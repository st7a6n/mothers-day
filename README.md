# Mother's Day Gallery

Open the gallery at:

```text
http://127.0.0.1:4173/
```

The local server is currently running from this folder.

## Customize

- Replace the photo URLs in `index.html` with your own image files or URLs.
- Edit the final letter text inside the `.letter-card` block in `index.html`.
- The default music is `assets/background-music.mp3`.
- The cover image is `assets/cover-photo.jpg`.
- The gallery photos are in `assets/gallery/`.
